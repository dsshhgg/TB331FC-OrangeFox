# 工具

本仓库不捆绑大体积工具，请自行下载：

| 工具 | 用途 | 获取 |
|---|---|---|
| platform-tools | adb / fastboot | Google 官方 SDK |
| QFIL / QPST / MultiPortQLoader | 9008 线刷 | 售后包 / 高通工具包 |
| 柚坛工具箱 | 刷机 GUI | 官方发布页 |
| avbtool + testkey | AVB 实验 | LineageOS `android_external_avb@lineage-23.2` |
| magiskboot | boot/recovery 解包 | Magisk 发行版 |

可选：把解压好的 `platform-tools`（约 10MB）放到本目录，或仅写下载说明。
